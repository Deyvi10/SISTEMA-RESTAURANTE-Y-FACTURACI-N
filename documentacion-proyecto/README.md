# Sistema Restaurante y Facturación

Punto de venta SaaS para restaurantes en Ecuador: comandas en tiempo real, caja, **facturación electrónica SRI**, inventario por recetas y analítica. Su arquitectura **Cloud-Edge** mantiene la operación del salón aunque se caiga el internet.
